# 0.4.0 — Clearer diff markers and navigation

## Highlights

- **Range flags in the editor:** green `+n` and blue `~n` mark current added/modified line ranges; red `−n` marks a deletion boundary. No full-width deletion rule or source-text tint. A fixed 32px gutter keeps source wrapping stable during refreshes.
- **Clearer diff text:** red old text, green added text, normal context, and stronger local word highlights in both default themes. Font-size and whitespace/highlight preferences remain available.
- **More readable sidebar:** compact controls, bordered reading groups and an on-demand reading guide. Long whitespace markers no longer spill outside their rows.
- **Explicit change counts:** navigation shows `Change 1 / 3`; group headings show a line range and their contained change count. Three changes can share two groups without combining their actions.
- **Precise navigation:** previous/next, group headings and change line-number buttons reveal the selected change. Source navigation respects the following preference and current viewing mode; body text remains selectable for clean Markdown copying.

## Safety and compatibility

- Desktop Obsidian **1.8.0+** and local Git are still required. No runtime dependency or minimum-host-version change. The development-only `source-map-js` dependency is patched to 1.2.2.
- Git operations remain read-only. Per-change restoration retains preview/confirmation, cancellation, fresh baseline/buffer checks and native editor undo.
- This release compares with **local Git HEAD**. Accepted-baseline review and GitLab integration are not enabled.
- Rendered tables and folded blocks use a first-change flag rather than an inaccurate internal range rail; the panel retains all independent changes and exact ranges. No automatic folding or content filtering is introduced.

## Validation

- 225 automated tests, lint, strict type checking, build and release consistency checks.
- 42 isolated Obsidian checks per language (English and Chinese), including navigation, copying, restoration/undo and narrow light/dark layouts.
- 36 whitespace-layout cases; covered long-document and large-deletion fixtures retain stable source width/left edge.
- Default-theme text contrast is checked on regular, selected and changed-word backgrounds. Third-party themes and navigation concurrent with an unfinished mode switch remain outside that guarantee.
- Production dependency audit reports no known vulnerabilities. Three moderate development-chain findings remain around the SDK's Moment dependency; these packages are not bundled into the plugin. The high-severity development-only source-map finding is patched.
