# 0.5.0 - First release of Better MD Diff Fork

The first release of this fork of [Better MD Diff](https://github.com/kamacheng/better-md-diff) 0.4.1.

## New

- **Word diff:** **Settings → Diff style** switches the panel between paired lines (default) and word views like `git diff --word-diff`: `[-deleted-]{+added+}` markers (plain) or red and green words (`--word-diff=color`). Words are split with the system word segmenter, so Cyrillic, CJK and punctuation compare word by word. Navigation, counts and restoration stay line based.
- **Compare with an earlier commit:** click **HEAD** in the panel header, run **Choose a commit to compare with**, or use **Compare with an earlier commit** in the file menu. The list shows the commits that changed the note, following renames. The panel, editor flags and restoration then use that commit for the note; **Back to HEAD** returns to the default. The choice lasts for the session.

## Changed

- New plugin ID `better-md-diff-fork` and name **Better MD Diff Fork**, so the community catalog never replaces it with the original. Settings of the original are not migrated. Enable only one of the two plugins at a time.
- The interface is English only; the Chinese translation is removed.

## Compatibility

- Desktop Obsidian **1.8.0+** and local Git, as before. Git stays read-only; restoration keeps confirmation, cancellation, freshness checks and one undoable edit.

## Validation

- 245 automated tests, lint, strict type checking, build and release checks, including a check that shipped files are English only.
- Not yet verified in a real Obsidian host for this release.
